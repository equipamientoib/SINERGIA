Alquiler de simulador de signos vitales (simulador de paciente ECG)

El simulador de signos vitales, también llamado simulador de paciente, genera señales de ECG, respiración y otros parámetros para comprobar que un monitor o un electrocardiógrafo mide y alarma correctamente, sin necesidad de un paciente real.

Preguntas frecuentes

¿Es lo mismo simulador de paciente que simulador de signos vitales?

Sí, son dos nombres para el mismo tipo de equipo: genera las señales fisiológicas que un monitor espera recibir de un paciente.

¿Qué parámetros simula el equipo disponible?

Revisa la ficha de cada modelo más abajo: ahí están los parámetros exactos que genera.

¿Sirve para verificar un monitor completo?

Para un monitor multiparámetro conviene combinarlo con el simulador de SpO2 y el manómetro; el paquete para monitores de paciente los incluye.
